# Investigación
La lectura conectada confirmó pestañas Integration Assessment (gid 0) y Ecommerce Assessment (gid 1952065539), columnas Meta de id/fecha/campaña/formulario, respuestas, email/full_name/company_name/phone_number/lead_status. El acceso HTTP sin credenciales al export CSV devolvió 200 text/csv sin cambiar permisos. Se elige este acceso de lectura para no ampliar OAuth de Calendar ni introducir secretos. La API Sheets privada necesitaría scope adicional: https://developers.google.com/workspace/sheets/api/scopes .
Se usa un cron dedicado para que una demora de Sheets no bloquee mailing, seguimiento o reuniones. No se llama a la ingesta de Meta porque puede enviar saludo; aquí solo se crean/actualizan contactos y oportunidades sin mensajes ni consentimiento automático.
